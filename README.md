# EduPlatform

Адаптивная образовательная веб-платформа для учителей и учеников.

## Цель

Учитель создаёт задания и тесты, назначает их классам и получает результаты. Ученик выполняет задания с телефона, планшета или компьютера и сразу видит процент выполнения и оценку.

## Первый MVP

- адаптивный интерфейс для ПК и телефона;
- переключение демо-роли «Учитель / Ученик»;
- кабинет учителя;
- список классов и активных заданий;
- журнал результатов;
- кабинет ученика;
- прохождение демонстрационного теста;
- автоматический расчёт процента и оценки.

## Следующие этапы

1. Авторизация и роли: администратор, учитель, ученик.
2. PostgreSQL и постоянное хранение данных.
3. Конструктор тестов и заданий.
4. Загрузка PDF, DOCX, PPT/PPTX.
5. Назначение заданий классам и отдельным ученикам.
6. Настраиваемая шкала оценок и количество попыток.
7. Экспорт результатов.
8. PWA-режим для установки сайта на главный экран.
9. Интеграции с Яндекс Формами / Google Forms при необходимости.

## Локальный запуск MVP

Откройте `index.html` в браузере.

На следующих этапах проект будет переведён на полноценный frontend/backend стек без изменения пользовательской концепции.
